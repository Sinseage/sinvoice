# SINVoice

Голосовой звонок для друзей по прямому IP: один поднимает сервер, остальные подключаются к нему.

Автор: Дмитрий Собенин (Sinseage)

## Возможности

- **Поднять сервер** — сервер запускается прямо в программе, вы автоматически входите в звонок.
- **Подключиться** — по адресу `IP` или `IP:порт` (порт по умолчанию 47800).
- **Голос** — по кнопке (глобальная клавиша или кнопка мыши, работает в играх) или по голосу (порог с индикатором уровня).
- **Шумоподавление** — встроенное шумоподавление и эхоподавление Chromium/WebRTC, включается переключателем.
- **Чат** — только на время звонка, нигде не сохраняется.
- **Файлы** — передаются вживую через сервер тем, кто сейчас в звонке. Сервер ничего не хранит: файл держится только в памяти получателя, пока идёт звонок, и сохраняется на диск кнопкой «Сохранить». Опоздавшие старые файлы не получают. Лимит — 2 ГБ на файл.
- **Оверлей** — компактный список участников слева сверху поверх всех окон, подсвечивает говорящих.
- **Настройки** — ник, аватар, устройства ввода и вывода, громкость микрофона и звука, тёмная или светлая тема, порт и пароль комнаты.

## Сборка через GitHub (с телефона)

1. Создайте репозиторий и загрузите в него содержимое архива так, чтобы `package.json` лежал в корне, а workflow — в `.github/workflows/build.yml`.
2. Откройте **Releases → Draft a new release**.
3. В **Choose a tag** введите новый тег в формате `v1.0.0` (только цифры через точку, с `v` впереди) → **Create new tag**.
4. Нажмите **Publish release**.
5. Через 5–8 минут в релизе появится файл `SINVoice-1.0.0.exe` (ход сборки виден во вкладке **Actions**).

Сборку можно запустить и без релиза: **Actions → Сборка SINVoice → Run workflow**. Тогда exe будет во вложении (Artifacts) к запуску.

Версия программы берётся из тега релиза автоматически.

## Сборка на компьютере

Нужен Node.js 20+.

```bash
npm install
npm run dist
```

Готовый файл — `dist/SINVoice-<версия>.exe`. Запуск без сборки: `npm start`.

## Как созвониться

1. Хост нажимает **Поднять сервер**. При первом запуске Windows спросит про брандмауэр — разрешите доступ.
2. Если компьютер хоста за роутером, на роутере нужно пробросить **TCP-порт 47800** (или ваш порт из настроек) на локальный адрес компьютера — он показывается под кнопкой после запуска сервера.
3. Друг вводит ваш внешний IP и жмёт **Подключиться**.
4. Пароль комнаты (необязательно) задаётся в настройках: хост защищает им сервер, участники вводят тот же пароль у себя.

## Что нужно знать

- exe — portable: один файл, без установки. При запуске он распаковывается во временную папку, поэтому первый старт занимает несколько секунд.
- Файл не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение: **Подробнее → Выполнить в любом случае**.
- Оверлей виден поверх игр в оконном режиме и режиме «Без рамки» (borderless). В эксклюзивном полноэкранном режиме Windows не даёт рисовать поверх игры никаким обычным окнам.
- Голос идёт несжатым PCM 24 кГц (около 400 кбит/с на говорящего). Для звонка 2–5 человек на домашнем интернете этого хватает; хост раздаёт голос каждого всем остальным, поэтому его исходящий канал нагружается сильнее.
- Настройки хранятся в `%APPDATA%\SINVoice`.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `main.js` | Окна, оверлей, запуск сервера, глобальная клавиша рации |
| `server.js` | Сервер комнаты: ретрансляция голоса, чата и файлов |
| `preload.js` | Безопасный мост между окнами и главным процессом |
| `src/app.js` | Интерфейс и логика звонка |
| `src/audio.js` | Захват микрофона, буфер джиттера, сведение голосов |
| `src/overlay.*` | Оверлей |
| `.github/workflows/build.yml` | Сборка exe в GitHub Actions |
